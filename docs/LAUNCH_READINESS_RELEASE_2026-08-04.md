# Lethela launch-readiness release — 4 August 2026

This release preserves the existing Lethela design, colours, layouts and public identity while strengthening the operational foundation for a controlled township-delivery launch.

## Included

- inventory-aware pre-launch, pilot and public marketplace wording
- safe empty-cart and WhatsApp-order behaviour
- road-distance delivery quotes with a conservative fallback
- secure reference-plus-phone order tracking
- structured support cases
- staged email verification
- vendor and rider onboarding guidance and reminders
- rider shift status and earnings summaries
- stricter liquor age handling
- public pricing information
- bookmarkable admin dashboard views and real attention records
- stronger bank-encryption, private-storage, restore, refund and launch gates
- updated dependency security and full CI validation

## Data safety

No production database reset, seed, deletion or schema migration was performed. No fake vendor, rider, product, licence, payment or order data was created.

## Remaining operational proof

Public commercial launch remains gated until real vendors, products and riders are approved; a controlled Ozow order and delivery are completed; the refund path is tested; private-storage access is verified; and a provider-side database restore drill is recorded.
